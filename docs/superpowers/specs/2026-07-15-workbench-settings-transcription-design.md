## 已确认方案

### 主内容顶栏

- 删除主内容区内部重复的页面标题、转写模型、总结模型和主题按钮整条顶栏。
- 保留最外层自定义 Windows 标题栏。
- 每个页面继续使用自身的 `page-heading` 展示标题、说明和页面状态。
- 主题切换移动到“设置 → 外观”，避免主工作区重复控制。

### 设置中心

设置页使用顶部胶囊分类导航，分类为：

1. 外观
2. 语音转文字
3. AI 总结
4. 模型管理
5. 数据管理
6. 关于

默认打开“语音转文字”。分类切换只更新设置内容，不离开设置页面。

### 语音转文字三种模式

语音转文字页面使用单选分段控件：

- CPU 模式：展示 whisper.cpp CPU、本地模型、语言、线程数和模型状态。
- GPU 模式：展示 whisper.cpp CUDA、显卡与显存状态、模型、CPU 回退和 CUDA 可用状态。
- 在线模式：展示在线服务商、接口地址、模型与凭据占位配置；原型不保存或读取真实凭据。

CPU/GPU 的模型下载、刷新和管理入口保留在当前设置模式内，不跳转首页。三种模式共用一致的卡片、状态标签和语言选择布局。

## 交互

- 点击设置分类切换对应面板，并同步 `aria-selected`。
- 点击 CPU/GPU/在线模式切换对应配置面板，并同步 `aria-selected`。
- 主题按钮在“外观”面板中切换明暗主题。
- 下载模型、检测 CUDA、验证在线服务等按钮只提供视觉反馈，不访问网络或真实系统凭据。

## 响应式与可访问性

- 大屏使用横向设置分类和左右配置布局。
- 窄屏允许分类横向滚动，配置区域改为单列。
- 交互目标不小于 44px；选中状态不只依赖颜色，并提供 ARIA 状态。
- 保留 `prefers-reduced-motion` 支持。

## 验收条件

- HTML 中不再存在主内容 `.topbar` 元素及旧模型胶囊。
- 设置页包含六个分类和 CPU/GPU/在线三种转写模式。
- 三种模式可点击切换，且模型管理不会导航到首页。
- 主题切换只出现在“外观”设置中。
- 结构测试、内联 JavaScript 语法检查和本地依赖扫描全部通过。
